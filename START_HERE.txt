🚀 نظام إبراهيم للمحاسبة المتقدم - جاهز للتشغيل!

📋 الخطوات السريعة:

1. تثبيت التبعيات:
   npm run install:all

2. إعداد البيئة:
   cp backend/env.example backend/.env

3. إعداد قاعدة البيانات:
   cd backend
   npx prisma migrate dev
   npx prisma db seed

4. تشغيل التطبيق:
   npm run dev

5. الوصول للتطبيق:
   Frontend: http://localhost:3000
   Backend: http://localhost:3001
