## 🛠️ التقنيات المستخدمة

### Backend
- **Node.js + Express + TypeScript**
- **Prisma ORM** مع PostgreSQL
- **JWT Authentication** مع Refresh Tokens
- **bcryptjs** لتشفير كلمات المرور
- **express-rate-limit** للحماية
- **helmet** للأمان
- **cors** لإدارة الطلبات المتقاطعة

### Frontend
- **React 18 + TypeScript**
- **Tailwind CSS** للتصميم
- **React Query** لإدارة البيانات
- **React Hook Form** للنماذج
- **React Router** للتنقل
- **React Hot Toast** للإشعارات
- **Heroicons** للأيقونات

### قاعدة البيانات
- **PostgreSQL** مع Neon Cloud (جاهزة ومعدة)
- **Prisma** كـ ORM
- **Migrations** تلقائية
- **Seeding** للبيانات الأولية
- **لا حاجة لتثبيت PostgreSQL محلياً**

## 🚀 التثبيت والتشغيل السريع

### المتطلبات
- Node.js 18+
- npm أو yarn
- اتصال بالإنترنت (للاتصال بقاعدة البيانات)

### خطوات التثبيت

1. **تثبيت التبعيات:**
```bash
npm run install:all
```

2. **إعداد متغيرات البيئة:**
```bash
cp backend/env.example backend/.env
# قاعدة البيانات Neon جاهزة ومعدة مسبقاً
# يمكنك تعديل JWT secrets إذا رغبت
```

3. **إعداد قاعدة البيانات:**
```bash
cd backend
npx prisma migrate dev
npx prisma db seed
```

4. **تشغيل التطبيق:**
```bash
npm run dev
```

5. **الوصول للتطبيق:**
- Frontend: http://localhost:3000
- Backend API: http://localhost:3001
