## التقنيات المستخدمة

### Backend
- **Node.js + Express + TypeScript**
- **Prisma ORM** مع PostgreSQL
- **JWT Authentication** مع Refresh Tokens
- **bcryptjs** لتشفير كلمات المرور
- **express-rate-limit** للحماية
- **helmet** للأمان
- **cors** لإدارة الطلبات المتقاطعة

### Frontend
- **React 18 + TypeScript**
- **Tailwind CSS** للتصميم
- **React Query** لإدارة البيانات
- **React Hook Form** للنماذج
- **React Router** للتنقل
- **React Hot Toast** للإشعارات
- **Heroicons** للأيقونات

### قاعدة البيانات
- **PostgreSQL** مع Neon
- **Prisma** كـ ORM
- **Migrations** تلقائية
- **Seeding** للبيانات الأولية

## التثبيت والتشغيل

### المتطلبات
- Node.js 18+
- PostgreSQL
- npm أو yarn

### خطوات التثبيت

1. **تثبيت التبعيات:**
```bash
npm run install:all
```

2. **إعداد متغيرات البيئة:**
```bash
cp backend/env.example backend/.env
# قم بتعديل ملف .env بالقيم المناسبة
```

3. **إعداد قاعدة البيانات:**
```bash
cd backend
npx prisma migrate dev
npx prisma db seed
```

4. **تشغيل التطبيق:**
```bash
npm run dev
```
